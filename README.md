# Global Superstore Power BI Dashboard

## 📊 Project Overview

This project is an interactive **Global Superstore Sales Analysis Dashboard** created using **Microsoft Power BI**.

The dashboard helps analyze sales, profit, quantity, customers, products, categories, and regional performance using interactive visuals, slicers, and DAX measures.

## 🛠️ Tools & Technologies

* Power BI
* Power Query
* DAX
* SQL
* Python
* Pandas
* CSV Dataset

## 📂 Dataset

The project uses the **Global Superstore dataset**, containing information about:

* Orders
* Customers
* Products
* Sales
* Profit
* Quantity
* Categories
* Sub-Categories
* Regions
* Countries
* Order Date
* Ship Date

## 📈 Dashboard Features

* Total Sales
* Total Profit
* Total Quantity
* Total Orders
* Sales by Region
* Sales by Category
* Sales by Sub-Category
* Profit Analysis
* Monthly Sales Trend
* Year-wise Sales Analysis
* Customer Analysis
* Product Analysis
* Interactive Slicers
* DAX Measures

## 🔄 Data Processing

The data was cleaned and transformed using **Power Query**.

Main steps included:

1. Removing duplicate records
2. Handling missing values
3. Correcting data types
4. Cleaning text columns
5. Validating Sales, Profit and Quantity
6. Creating calculated columns
7. Creating DAX measures
8. Building interactive Power BI visuals
